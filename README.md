# Убить пересмешника — айсберг смыслов

Интерактивный сайт по роману Харпер Ли. Страница прокручивается как погружение: сверху закат и вершина айсберга (сюжет), ниже вода темнеет, и на каждом уровне открываются скрытые темы, символы, психология и философские вопросы. На самом дне горит одна лампа.

**Стек:** React 19, TypeScript, Vite. Анимации на CSS, canvas и собственном «двигателе» скролла, звук синтезируется Web Audio API. Аудио- и видеофайлов в проекте нет, внешних библиотек анимации тоже.

## Запуск

Нужен Node.js 20.19 или новее (лучше 22).

```bash
npm install
npm run dev       # разработка: http://localhost:5173
npm run build     # готовая сборка в папке dist
npm run preview   # посмотреть собранную версию
```

## Публикация на GitHub Pages

1. Создайте на github.com новый репозиторий (например, `mockingbird-iceberg`). Для бесплатных Pages он должен быть **публичным**.
2. Загрузите проект:

   ```bash
   git init
   git add .
   git commit -m "Айсберг смыслов"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/mockingbird-iceberg.git
   git push -u origin main
   ```

3. На GitHub откройте **Settings → Pages**, в поле **Source** выберите **GitHub Actions**.
4. Откройте вкладку **Actions**: сборка запустится сама после push. Через минуту-две сайт будет на `https://<ваш-логин>.github.io/mockingbird-iceberg/`.

Дальше каждый `git push` в `main` обновляет сайт автоматически. Путь в Vite относительный (`base: './'`), поэтому имя репозитория нигде прописывать не нужно.

После первого `npm install` в проекте появится `package-lock.json`: добавьте его в коммит. Тогда в `.github/workflows/deploy.yml` шаг `npm install` можно заменить на более строгий `npm ci`.

## Как поменять картинки

Главный фон, картинка айсберга, лежит в `public/images/bg/background.jpg`. Чтобы заменить его, положите свою картинку с тем же именем. Если у неё другие пропорции, поправьте три константы в начале `src/components/Iceberg.tsx`: `IMG_ASPECT` (ширина к высоте), `WATERLINE` (где на картинке линия воды) и `LAMP_Y` (где лампа). Скрипт `tools/prepare_background.py` (нужны opencv-python и numpy) показывает, как исходник очищался от цифр и разделителей и увеличивался. Иконки нарисованы кодом. Остальные картинки необязательные, имена файлов фиксированные в `public/images/`:

| Файл | Где появится |
| --- | --- |
| `mockingbird.jpg` | окно темы «Символика пересмешника» |
| `atticus.jpg` | окна тем «Семья Финчей» и «Моральное мужество» |
| `scout.jpg` | окна тем «Детство Скаут и Джема» и «Взросление и потеря невинности» |
| `boo-radley.jpg` | окна тем «Бу Рэдли» и «Страх перед неизвестным» |

Если файла нет, окно показывает нарисованную иконку. Привязку фото к темам можно поменять в поле `image` в `src/data/meanings.ts`. Чтобы заменить фавикон, подмените `public/favicon.svg`.

## Как поменять тексты и темы

Всё в одном файле, `src/data/meanings.ts`:

- **Новая тема:** допишите объект в массив `cards` нужного уровня (заголовок, краткий текст, строка при наведении, иконка, абзацы для окна, вопрос).
- **Тексты уровней:** поля `title`, `description`, `depthRange` у каждого уровня.
- **Главный экран:** объект `heroText` в конце файла.
- **Финал:** объект `finalText`.
- **Иконки тем:** поле `icon`, доступные названия перечислены в типе `IconName` (рисунки лежат в `src/components/Icons.tsx`).

Цвета и размеры шрифтов задаются в `src/styles/index.css`, в блоке `:root` в самом начале. Цвета неба, воды и льда внутри сцены лежат в `src/components/Iceberg.tsx`.

## Шрифты

Cormorant Garamond (заголовки) и Manrope (интерфейс) подключаются из Google Fonts без блокировки отрисовки. Если Google Fonts недоступен, сайт переходит на системные шрифты (Georgia и системный sans-serif) и не ломается. Чтобы шрифты были «свои» и не зависели от Google, скачайте их, положите файлы в `public/fonts/` и пропишите `@font-face` в начале `index.css`.

## Звук

Кнопка в правом верхнем углу. Звук не включается сам. Вода, ветер, подводный гул и далёкие птицы синтезируются в браузере и меняются с глубиной: у поверхности слышны ветер и птицы, внизу остаётся глухая вода и низкий гул.

## Доступность и производительность

- Если в системе включено «уменьшить движение» (`prefers-reduced-motion`), анимации и плавание частиц отключаются, блоки появляются сразу.
- На слабых устройствах (мало ядер или памяти) частиц вдвое меньше, лучи и размытие упрощаются. Если кадры всё равно идут медленно, частицы убавляются автоматически.
- Все карточки доступны с клавиатуры, окно закрывается по Esc, фокус не уходит за его пределы.
